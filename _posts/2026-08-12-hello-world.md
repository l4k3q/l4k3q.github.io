这是博客的第一篇文章。从今天起，我会在这里记录一些技术笔记、折腾过程和一些碎碎念。

这个博客基于 Jekyll + GitHub Pages 搭建，所有文章都是 Markdown 写的，代码高亮、图片、列表、引用全都能正常渲染。比如下面这段代码：

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

也可以用行内代码，比如 `jekyll build`、`git push`，或者引用一段话：

> 写文章是最好的自我投资。
